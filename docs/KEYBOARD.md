# Keyboard

| Keys | Where | Does |
|---|---|---|
| Ctrl+K | anywhere (not inside a terminal) | command palette: projects, tickets, PRs, Workspace commands |
| N | anywhere, not typing | new ticket |
| 1–9, 0 | anywhere, not typing | jump to a screen in the rail order |
| / | lists | focus search |
| Esc | dialogs, menus, palette | close |
| Ctrl+\ | anywhere (not inside a terminal) | collapse the navigation rail; in the HQ preview, only in a window wider than 1440px (narrower, its sidebar is icons already) |
| Ctrl+. | Workspace | Workspace Focus: no rail or top bar |
| Alt+Shift+O | an HQ page with Pop out | open the page in its own window |
| Ctrl+P | Workspace (not inside a terminal) | go to file |
| Ctrl+Shift+F | Workspace (not inside a terminal) | open the sidebar in Search mode and focus the query |
| Ctrl+S | Workspace editor | save (Developer Mode) |
| Ctrl+B | Workspace | show / hide the sidebar (Explorer, Source control or Search). Clicking the active icon in the activity bar does the same |
| Ctrl+` | Workspace | show / hide the terminal panel |
| Ctrl+Shift+` | Workspace | open the Project terminal |
| Ctrl+Shift+Enter | Workspace | maximize / restore the dock (Claude, Project, Server) |
| Ctrl+V, Ctrl+Shift+V, Shift+Insert | a browser terminal | paste (the program's bracketed-paste mode is honoured; nothing is sent until you press Enter in a shell) |
| Ctrl+C | a browser terminal | copy when text is selected; otherwise ^C (interrupt) |
| Shift+F10 or the Menu key | explorer row | context menu |
| ← → / ↑ ↓ (Shift = bigger) | a focused divider | resize the sidebar / dock |

Inside a real terminal, Ctrl+K, Ctrl+P, Ctrl+S, Ctrl+B and Ctrl+Shift+F go to the
shell (Ctrl+P is history, Ctrl+K kills to end of line). F11 is left to the
browser.
