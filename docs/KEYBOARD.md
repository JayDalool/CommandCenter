# Keyboard

| Keys | Where | Does |
|---|---|---|
| Ctrl+K | anywhere (not inside a terminal) | command palette: projects, tickets, PRs, Workspace commands |
| N | anywhere, not typing | new ticket |
| 1–9, 0 | anywhere, not typing | jump to a screen in the rail order |
| / | lists | focus search |
| Esc | dialogs, menus, palette | close |
| Ctrl+P | Workspace (not inside a terminal) | go to file |
| Ctrl+Shift+F | Workspace (not inside a terminal) | search in project |
| Ctrl+S | Workspace editor | save (Developer Mode) |
| Ctrl+B | Workspace | show / hide the explorer |
| Ctrl+` | Workspace | show / hide the terminal panel |
| Ctrl+Shift+` | Workspace | open the repo shell |
| Ctrl+Shift+Enter | Workspace | maximize / restore the terminal |
| Shift+F10 or the Menu key | explorer row | context menu |
| ← → / ↑ ↓ (Shift = bigger) | a focused divider | resize the explorer / terminal |

Inside a real terminal, Ctrl+K, Ctrl+P, Ctrl+S, Ctrl+B and Ctrl+Shift+F go to the
shell (Ctrl+P is history, Ctrl+K kills to end of line). F11 is left to the
browser.
