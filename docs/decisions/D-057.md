## What Jay approved as the design

Jay may later issue a **temporary scoped lease** that lets Claude or Codex access a specific project or worktree on
`jay-laptop-wsl`.

A lease must be:

- explicitly approved by Jay;
- bound to the agent and its provider;
- bound to one project;
- bound to one WorkerNode;
- bound to named capabilities;
- time limited;
- revocable at any time;
- audited.

### Modes

| Mode | Meaning |
|---|---|
| INSPECT | Read only. |
| ASSISTED | Changes proposed; Jay applies or approves each one. |
| INTERACTIVE | Works in the worktree within the lease's capabilities. Every action still goes through the Broker and any approval it requires. |

### The rule

A D-057 lease can only **reduce** existing authority. It never creates authority that the agent, project, task or
Broker does not already grant. Effective authority stays the intersection of actor identity, agent grant, project
profile, task mode, WorkerNode capability, requested capability, approval state and data-egress policy, with the
lease as one more term in that intersection.
