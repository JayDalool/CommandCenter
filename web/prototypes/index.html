Look for

  1. Overview: can you answer the five questions in five seconds? Server healthy · what's working · what's blocked · what needs you · what changed.
  2. Agents: the blocked implementer is expanded inline with its question and an answer box.
  3. Pull requests: are the rows that need you obvious without shouting?
  4. Server: is it compact, and is the worktree warning clear but calm?
  5. Offline: does the stale state look trustworthy rather than broken?

Keyboard (all three)

  • 1–9 screens · Ctrl K palette · ? all keys
  • j k rows · Enter expand · Esc collapse
  • F focus pane · A answer a blocked agent
  • T tasks table ↔ pipeline · [ ] filters
  • D dark ↔ light · Shift O simulate offline

Also notice

  • Two events arrive on their own in the first minute: watch Activity.
  • Every state is a shape and a word, never colour alone.
  • There is no merge, deploy or delete anywhere — those don't exist in the API.
  • Context / tokens show “—” on purpose (deferred).
  • Settings has the prototype controls: offline, loading, insert an event.
